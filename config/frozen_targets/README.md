# Frozen experiment targets

These files are source-derived inputs to the factorial experiment. They are
not generated by an LLM.

The selection rule is fixed across all six benchmarks: target every
source-defined computational function reachable from `main`; exclude the
benchmark driver (`main`), LOCAL_RUN-only I/O, simulator hooks, and unreachable
dead code. A locally implemented numerical helper is computational source and
is therefore included even when its name resembles a library function.

This rule deliberately includes `stringsearch-iclib:init_search`. The previous
LLM selection excluded it and thereby ruled out the measured exact keyed-reuse
opportunity before planning began.
