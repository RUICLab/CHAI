====================================================================================================
READING THIS TABLE
====================================================================================================
  HW-infeasible is the direct hardware-awareness measure: an operator
  the target physically cannot run. CHAI's gatekeeper removes these
  before the model ever sees them, so a non-zero count in an arm with
  the control plane ON would be a defect, not a design choice.

  false provenance is a LOWER BOUND from a static + behavioural
  checker; it cannot prove a transformation is genuinely present.

  menus = 1 means every function was offered the identical operator
  list. Greater than 1 means the plan was specialised per function.
