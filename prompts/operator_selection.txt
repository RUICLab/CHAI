Selection rules:
- Choose an operator ONLY if this specific function contains the code structure
  the operator acts on. An operator that is feasible for the application as a
  whole is often meaningless for an individual function.
- A loop-based operator requires a loop in THIS function.
- A precision operator requires arithmetic in THIS function.
- A data-structure or spectral operator requires that data structure or that
  transform in THIS function.
- T3 exact keyed reuse is the call-site exception: select it for a callee that
  recomputes reusable state when the supplied SOURCE CALL-SITE CONTEXT proves
  repeated calls with a stable key. The repeated loop can be in the caller.
  Do not claim T3 from the callee body alone when no call-site evidence exists.
- If a function is a small accessor, a wrapper, or pure control flow, it is
  correct to select nothing at all.
- Select at most {max_operators} operators. Prefer the smallest set that could
  plausibly reduce this function's cycle count.
