For a function `void filter(int *buf, int n)` containing

```
- OPERATOR: T1
  REGION: the for loop over i in buf[i]
  KNOB: iteration_pct | Integer | RANGE [50, 100] | IDENTITY 100
  BENEFIT: iterations
  PRECONDITION: n > 0 and buf holds at least n elements
  INVARIANT: every written element stays within the original value range

RATIONALE: Truncating the loop removes iterations proportionally, and at
iteration_pct = 100 the function is identical to the original.
```

Note three things that make that KNOB line valid, because these are the most
common mistakes:

1. **IDENTITY is present.** It names the value at which the function
   reproduces the original exactly. It is never optional.
2. **The RANGE is not a single point.** `RANGE [1, 1]` gives the optimizer
   nothing to search and describes a no-op, not an approximation.
3. **The knob is a NEW variable name.** Never reuse a parameter or an existing
   local (here `n`, `i` and `buf` are all forbidden as knob names).
